# Research opportunities and closure ledger

| Opportunity | Problem and acceptance criteria | State |
| --- | --- | --- |
| Bounded browser worker + raster font-ink canary | Headless Chromium `page.evaluate` can stall without obeying `set_default_timeout`, and font readiness can resolve without glyph ink. Isolate Chromium in a dedicated process group with hard wall-clock readiness/draw timeouts and alpha ink verification | **verified** (`BrowserWorkerResilienceTests` + `BrowserIntegrationTests`) |
| Morphological stemming, negation, and drone disambiguation | Suffix inflections missed Turkish queries while `"no audio, cinematic drone"` matched camera `aerial-shot`. Deduplicate stemmed word tokens, scope negative clauses, and disambiguate audio vs aerial drone contexts | **verified** (50-case eval: `0%` no-match error, `0%` hard-constraint violations) |
| Unified progressive MCP Gateway | Exposing 573 raw `BlenderMCP` + `AfterEffectsMCP` tools bloats context and collides on `render_preview`. Expose 9 constant meta-tools with `blender:*` / `after_effects:*` namespacing and lazy schema promotion | **verified** (`GatewayAndMcpSimulatedTests` + live 573-tool introspection) |
| Blender 5.x OCIO `AgX` and rational FPS | Static `bl_rna` enum inspection misses `CYCLES` and `AgX` in Blender 5.1, and integer FPS drifts on `1001` rates. Configure live scene instances and set both `fps` and `fps_base` | **verified** (`test_blender_engine_fallback_and_live_headless_render` on Blender 5.1.2) |
| H.264 VUI + MP4 `colr` BT.709 preservation | Stream-copying scene MP4s via `concat` dropped `color_transfer` and `color_primaries` in FFmpeg 9.0. Write VUI (`-x264-params`) and muxer color flags explicitly | **verified** (`reelsyntax qc` `color_metadata: pass`) |
| Lossless ROI pixel locks and editorial interchange | Revising motion graphics must not alter locked compliance/brand bars, and editors need editable timelines. Hash lossless pre-encode ROI crops and export `.otio`, `.fcpxml`, `.vtt`, `.srt`, and `.svg` | **verified** (`ProductionLibrariesUnitTests` + `ProductionMediaPipelineTests`) |
| Live application bridge round-trip | Requires a reachable application bridge independently of headless rendering | **blocked locally** (Blender bridge refused connection; After Effects project-info MCP request timed out after 300s; desktop UI automation excluded) |
| Local source footage and raster/PSD composition | Combine source video with normal-alpha layers, preserve assets and fail on unsupported PSD appearances | **verified within supported formats** (source hashes, trim/layer/stereo tests and editorial example QC) |
| Frame-anchored source audio | J/L cuts need audio timing independent of picture cuts with sample-aligned endpoints | **verified** (source stems, fractional FPS endpoint regression and short-source refusal) |
| Bounded scene cache growth | Retain delivered scene references while reclaiming old content-addressed entries | **verified** (dry-run/apply LRU, shared mutex, symlink/unknown-data protections) |
| Headless WebGL2 studio recipe | Add shader-based 3D without a mandatory Node/Three.js runtime | **verified on SwiftShader** (deterministic seeks, mixed Canvas/WebGL and actual encode; custom shader authoring remains future work) |
| Native editable editorial project | Verify an actual NLE save/reopen and decoded frame instead of JSON/XML structure alone | **verified on Blender 5.1.2 Video Sequencer**; other NLE applications remain separate gates |
