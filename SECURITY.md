# Security boundaries

Local footage/audio ingest selects an explicit allowlisted container demuxer and permits only the file protocol; playlists are unsupported. Source assets are project-contained files with content hashes verified before delivery and QC/export. Optional PSD extraction uses bounded 8-bit RGB raster parsing through an already installed local Node runtime and rejects unsupported compositing. Cache pruning shares the render mutex, protects current delivery references and rejects symbolic links.

ReelSyntax is a local CLI, not an OS sandbox. Run it against authorized, reviewed projects. Skill text, reference documents and media are untrusted data and never override owner or host permissions. The router never executes a skill, installs software, downloads assets or contacts a model/service.

Managed paths reject traversal, absolute paths and symlinks beneath the selected root. Registry IDs, fields, dependencies and digests are checked. Selected instruction/resource bodies are hash checked before disclosure. Local hashes detect drift and corruption; they are not publisher signatures and do not defend against an attacker who controls the checkout and its index. Review third-party skill additions before reindexing. Filesystem checks cannot fully prevent a concurrent malicious filesystem actor; use normal OS isolation for hostile inputs.

The declarative render baseline does not accept arbitrary Python, JavaScript, HTML or shell commands in plans. Browser pages are generated by the installed renderer; service workers, downloads and network requests are blocked. Chromium's sandbox stays enabled. This policy is tested only when the browser integration test actually runs.

Media processes use argument arrays, timeouts and a reduced environment. POSIX timeout/cancellation kills the child process group; Windows currently kills the direct process. No arbitrary-command MCP tool or remote worker exists. Output masters are replaced only after probe/decode checks; prior masters remain in local history. Scene caches are local, hash checked and not shared across machines by an unauthenticated protocol.

No telemetry, credentials, paid API calls or external publication is part of the runtime. Do not put personal media, secrets, `.env`, local state, binary dependencies or generated masters in public source control. Report suspected vulnerabilities privately to the repository owner using an available private GitHub reporting route; do not publish exploit details or credentials in an issue. No formal security certification is claimed.

The Unified MCP Gateway validates published meta-tool arguments before dispatch, including real boolean policy values, nested types, numeric bounds and nullability. `mcp --workspace PATH` restricts ReelSyntax project validate/plan/QC calls to an explicit existing root; relative paths resolve there, and outside paths, traversal and nested symlinks are refused. The default root is the launch directory. This project boundary does not sandbox downstream Blender/After Effects tools or their native script/path permissions.

The stdio reader bounds messages to 1 MiB and compatibility headers to 8 KiB. Malformed JSON, duplicate object keys, non-finite constants and invalid frame lengths cannot become tool calls. Invalid complete JSON messages return protocol errors; unrecoverable framing closes the connection. The schema checker supports the documented subset in `docs/first-party-mcp.md`; it is not a replacement for the downstream server's complete validation.

## Local extensions and authoring inputs

An installed Python recipe runs with the caller's OS permissions when explicitly selected by `from-plugin --allow-plugin`. Review the package before enabling it. Keep this operation out of untrusted CI jobs. A `three-scene` browser bundle requires `--allow-browser-module` on every render or resume. Browser assets remain local and the worker has a per-operation timeout. The gateway does not enable either extension flag.
