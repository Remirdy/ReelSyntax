# ReelSyntax Skill Catalog

500 original production-guidance skills (v2); 25 categories, 20 each. Human-facing catalog only. Do not load this file into an agent context for ordinary production tasks.

## Creative direction and production planning (20)

| Skill | Turkish / alternate triggers | Scope |
|---|---|---|
| `brief-decoding` | brief çözümleme, istek analizi | Extract audience, purpose, duration, format and non-negotiable constraints; separate facts from assumptions. |

| `concept-divergence` | yaratıcı fikir, alternatif konsept | Draft three concepts with different visual mechanisms, not just colors; compare cost and feasibility. |
| `audience-mapping` | hedef kitle, izleyici | Map audience knowledge, context, expectations and reading speed to narrative decisions. |
| `message-hierarchy` | mesaj sıralaması, ana mesaj | Rank one core claim and supporting claims; assign emphasis and screen time accordingly. |
| `reference-analysis` | referans video, örnek video | Sample shots, measure cuts, infer camera paths and characterize color and typography without cloning assets. |
| `visual-language-bible` | görsel dil, stil rehberi | Specify shape vocabulary, texture, contrast, typography, movement and forbidden motifs. |
| `style-selection` | stil seçimi, görsel tarz | Compare stylistic options against brief, asset availability and compute budget. |
| `tone-calibration` | duygu, video tonu | Define emotional start/end and beats; map intensity to motion, music and color. |
| `creative-constraint-lock` | kısıtlar, kamera sabit, yazı olmasın | Convert prohibitions and fixed properties into explicit locks before scene construction. |
| `production-scope` | iş kapsamı, prodüksiyon planı | Break work into deliverables, dependencies and milestones with cost classes. |
| `engine-selection` | motor seçimi, render motoru | Score candidates by output type, installed tools, licenses, reproducibility and fallback options. |
| `shot-budget` | sahne bütçesi, çekim sayısı | Distribute frames over story beats and calculate shot and render cost from explicit assumptions. |
| `asset-feasibility` | asset uygunluğu, varlık listesi | Inventory source availability, permissions, quality, and substitutes before committing to concepts. |
| `creative-risk-review` | yaratıcı risk, konsept kontrol | Identify readability, originality, complexity and production risks with mitigation tests. |

| `reeltaste-profile` | tercih hafızası, kişisel stil | Store explicit approved/rejected preferences locally with project scope and opt-out. |
| `brand-brief` | marka briefi, kurumsal kimlik | Extract approved logos, colors, fonts, restrictions and required legal copy from supplied assets. |
| `series-planning` | seri planı, bölüm planı | Create a reusable series bible, episode structure and visual continuity ledger. |
