# Film Noir

## Activation
Use for film noir when it is a concrete work item. Search aliases: film noir,siyah beyaz sinema. Do not activate for generic video language alone. Read the project brief and relevant hard locks before changing any asset.

## Inputs and output
- Inputs: Brief, references, asset permissions and output canvas.
- Output: Visual direction specification and representative frames.
- Required capability: No specific adapter is mandated; inspect the chosen implementation path.
- Evidence bundle: style tokens and three representative frames.

## Production recipe
1. Locate shot/task IDs, approved assets, frame rate, duration and relevant constraints. Verify required capability; record assumptions and do not silently substitute missing resources.
2. Build high-contrast monochrome lighting, occlusion and motivated silhouettes.
3. Use directional hard key, controlled fill and meaningful shadow shapes; retain essential face detail and check exposure after grade.
4. Record actual parameters in the editable source or project manifest; produce a representative preview or dry run before full execution. Apply only parameters relevant to the brief, not every technique in this skill.
5. Review grayscale, silhouette, thumbnail and target-size views under a consistent output transform.

## Acceptance criteria
- Shadow detail remains intentional rather than accidental clipping.
- Record the concrete evidence path and frame/time range or measurement, plus target/tolerance and result (`pass`, `fail`, `review`, `blocked`, `not-applicable`). Never award a pass for an unperformed check.
- Check this stage against active project locks and the production profile. Aesthetic judgment requires actual visual/audio review; technical gate success is necessary but not sufficient for release.

## Failure and repair
Reduce competing visual elements, revise hierarchy or material/lighting contrast; preserve intentional style. If the required implementation is absent, return the exact blocker and an executable plan; do not present guidance as a rendered result. Recheck the original acceptance condition after repair.
