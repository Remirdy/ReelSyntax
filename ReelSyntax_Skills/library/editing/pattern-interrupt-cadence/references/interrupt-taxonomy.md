# Pattern Interrupt Modality Taxonomy and Spacing Guide

| Modality | Parameter Signature | Best Linguistic Trigger |Incompatible Lock |
| --- | --- | --- | --- |
| `scale_step` | Instant `1.18x–1.30x` crop on cut | Precision detail, Caveat | `camera_locked` (if crop counts as reframe) |
| `polarity_flip` | Controlled dark `<->` mid-light slate swap (`ΔL <= 0.55`) | Counter-argument (`"But"`, `"Ama"`, `"Aber"`) | Flash-safety ceiling (`<= 3` flips/sec, never rapid) |
| `spatial_split` | Single canvas splits into `A | B` columns | Direct comparison, before/after | Narrow `> 22` char headings |
| `callout_badge` | Pill highlight or arrow locks onto target region | Numeric proof, step marker | `no_text` (use pure shape arrow instead) |
| `sonic_drop` | `8–12f` music mute + subtle low transient | Core thesis sentence | `no_audio` |
