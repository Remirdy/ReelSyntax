# Cinematic Drone

## Activation
Use for cinematic drone when it is a concrete work item. Search aliases: drone müzik,atmosferik pad. Do not activate for generic video language alone. Read the project brief and relevant hard locks before changing any asset.

## Inputs and output
- Inputs: Approved cue brief, timeline, source rights and tempo.
- Output: Original score, MIDI, cue sheet or audio stems.
- Required capability: No specific adapter is mandated; inspect the chosen implementation path.
- Evidence bundle: original event/cue data, instrument provenance and stems.

## Production recipe
1. Locate shot/task IDs, approved assets, frame rate, duration and relevant constraints. Verify required capability; record assumptions and do not silently substitute missing resources.
2. Layer slow evolving tones with dissonance and low-end controlled by intent.
3. Build evolving low texture with slow modulation and sparse harmonics; avoid masking speech; apply smooth loop boundaries.
4. Record actual parameters in the editable source or project manifest; produce a representative preview or dry run before full execution. Apply only parameters relevant to the brief, not every technique in this skill.
5. Review phrase boundaries, melody originality, dialogue masking, dynamics and loop seam.

## Acceptance criteria
- Drone supports scene mood without distracting modulation.
- Record the concrete evidence path and frame/time range or measurement, plus target/tolerance and result (`pass`, `fail`, `review`, `blocked`, `not-applicable`). Never award a pass for an unperformed check.
- Check this stage against active project locks and the production profile. Aesthetic judgment requires actual visual/audio review; technical gate success is necessary but not sufficient for release.

## Failure and repair
Change orchestration, timing or harmony; preserve licensed/source constraints and avoid copied motifs. If the required implementation is absent, return the exact blocker and an executable plan; do not present guidance as a rendered result. Recheck the original acceptance condition after repair.
