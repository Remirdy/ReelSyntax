# Ending Payoff

## Activation
Use for ending payoff when it is a concrete work item. Search aliases: kapanış,final sahne. Do not activate for generic video language alone. Read the project brief and relevant hard locks before changing any asset.

## Inputs and output
- Inputs: Brief, scene IDs, duration, approved sources where applicable.
- Output: Timecoded script, shot plan or continuity artifact.
- Required capability: No specific adapter is mandated; inspect the chosen implementation path.
- Evidence bundle: timecoded beats, shot ledger and animatic.

## Production recipe
1. Locate shot/task IDs, approved assets, frame rate, duration and relevant constraints. Verify required capability; record assumptions and do not silently substitute missing resources.
2. Resolve the central promise with a visual callback or decisive action.
3. Seed one visual motif or question early, then return with altered meaning; avoid repeating the entire summary in an end card.
4. Record actual parameters in the editable source or project manifest; produce a representative preview or dry run before full execution. Apply only parameters relevant to the brief, not every technique in this skill.
5. Review causal order, readability and playback timing with and without audio.

## Acceptance criteria
- Final shot is meaningful without an unnecessary summary.
- Record the concrete evidence path and frame/time range or measurement, plus target/tolerance and result (`pass`, `fail`, `review`, `blocked`, `not-applicable`). Never award a pass for an unperformed check.
- Check this stage against active project locks and the production profile. Aesthetic judgment requires actual visual/audio review; technical gate success is necessary but not sufficient for release.

## Failure and repair
Reallocate frames, cut redundant beats or repair coverage; preserve approved facts and ending. If the required implementation is absent, return the exact blocker and an executable plan; do not present guidance as a rendered result. Recheck the original acceptance condition after repair.
